# Changelog

## 0.6.0 — 2026-09-08

- Separate learning goals, interests, levels and progress for each user/language.
- Installed-agent settings and independently selectable explanation language.
- Dedicated dynamic learning workspace with an offline Three.js constellation,
  accessible controls, reduced-motion support and a 2D fallback.
- Persistent view state, review self-checks and stale-answer protection.
- Cosmos memory collaboration for lasting goals, progress and recurring difficulties.

Requires Cosmos 0.3.0 or later. Older cores show an upgrade message without
modifying learning files. Existing ownerless local files migrate only in a verified
single-user local context; named accounts never inherit another user's progress.

Actual voice/video learning and learner acceptance remain follow-up validation;
the release does not claim verified fluency or automatic pronunciation assessment.
