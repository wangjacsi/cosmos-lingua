# Lingua Live — 실시간 언어 학습 에이전트

> 코스모스(cosmos-billy) 마켓 에이전트. 음성으로 대화하면서 **수준을 재고, 흐름을 끊지
> 않고 교정하고, 잊을 때쯤 다시 꺼내 주는** 튜터.
> 영어 · 스페인어 · 일본어 · 중국어 · 독일어 · 프랑스어 · 한국어 · 아랍어
> (+ 이탈리아어 · 포르투갈어 · 러시아어)

설치: 코스모스 **🛒 마켓 → Lingua Live → 설치**. 화면은 **🧩 에이전트 뷰**에 열린다.

## 개발 중 — 개인별·언어별 학습 (아직 마켓 미배포)

이 작업본은 Cosmos의 `load_agent_state` / `save_agent_state` 계약을 포함한 코어가 필요하다.
출시된 0.5.2와 같지 않다. 원본 테스트와 격리 화면 검증 후 실제 음성 학습·업데이트 검증이 남아 있다.

- 사용자마다 언어·학습 순서를 정하고, 언어별 목표·수준·카드·복습·보고서를 따로 이어간다.
- 뷰를 Cosmos 내부 또는 별도 창에서 열 수 있다. Today는 독자적인 동적 학습 공간이다.
  Three.js 별자리는 실제 표현·복습 상태를 반영하며, 직접 답 작성 → 예시 비교 → 자기 점검으로
  복습 일정을 갱신한다. 자동 채점/유창성 점수가 아니다. 저장된 학습 변화는 5초 간격으로 표시한다.
  같은 항목의 갱신에서 입력·3D 상태를 유지하고, 모션 중단·숨김/복귀·2D 대체를 지원한다.
  이 뷰는 새로운 코어 `html.key/state/libraries` 및 `cosmos.onState/onLifecycle` 계약이 필요하다.
- 목적은 자연스러운 대화 능력. 관심 주제·상황극·같은 표현의 다양한 예시로 연습한다.
- 학습 언어, 화면 언어, 설명 언어를 구분한다. 사용자 목표나 모국어를 임의로 확정하지 않는다.
- 실제 영상 검색·자막·시청 구간을 연습과 연결하는 기능은 **다음 구현 범위**다.
  현재는 실제 출처를 확인하지 않은 영상·자막을 지어내지 않도록 학습 지침을 적용했다.

검사: `../cosmos-billy/venv/bin/python -m pytest tests -q`.
화면: `../cosmos-billy/venv/bin/python scripts/preview_profiles.py` (격리 데이터·실제 뷰 렌더러).
UI 검사: `node scripts/check_profiles_ui.mjs`, `node scripts/check_learning_ui.mjs` (Playwright 필요).
`LINGUA_PLAYWRIGHT_MODULE`로 설치된 모듈의 경로를 지정할 수 있다.
3D 검증은 테스트용 SwiftShader, 2D 검증은 WebGL 비활성 브라우저를 사용한다.
실제 모델/음성 지연 및 설치 업데이트를 검증한 것은 아니다. 새 화면 어휘는 영어/한국어이며
다른 UI 언어의 미번역 문구는 영어로 보인다.

## 왜 또 하나의 언어 앱이 아닌가

대부분의 언어 학습 도구는 **정확도**를 최적화한다. 틀리면 즉시 알려주고, 점수를 매기고,
다음 문제로 넘어간다. 그런데 사람이 외국어를 못 하게 되는 진짜 이유는 문법을 몰라서가
아니라 **입이 안 떨어져서**다. 즉시 교정은 정확도를 잠깐 올리는 대신 발화량을 줄이고
불안을 키운다. 말을 덜 하게 만드는 학습법은, 아무리 정확해도 실패한다.

Lingua Live는 그 반대 순서를 택한다: **먼저 말하게 하고, 교정은 흐름을 지키며 주고,
그 교정이 사라지지 않게 시간을 두고 되돌린다.**

## 교육 철학 (이 일곱 줄이 모든 설정의 근거다)

**① 말이 멈추면 학습도 멈춘다.**
발화량이 곧 연습량이다. 그래서 기본 교정 방식은 대화를 끊지 않는 **되풀이(recast)** 다 —
학습자가 한 말을 올바른 형태로 자연스럽게 되받아 주고 계속 간다. 즉시 교정은 *선택*이지
기본이 아니다.

**② 한 걸음 위를 듣는다 (i+1).**
지금 수준에서만 놀면 늘지 않고, 너무 어려우면 닫힌다. 튜터는 늘 **한 단계 위**로 말한다.
그 '한 단계'는 고정값이 아니라 실측으로 움직인다(→ ⑥).

**③ 이해했다고 아는 게 아니다 (밀어붙인 산출).**
알아듣는 것과 말할 수 있는 것은 다르다. 교정 뒤에는 **다시 말해보기**를 요구한다.

**④ 모든 오류를 고치지 않는다.**
한 번에 다 고치면 하나도 남지 않는다. 같은 오류가 **두 번** 반복될 때만 승격하고,
한 세션에서 다루는 교정 항목은 **최대 3개**다. 나머지는 조용히 기록만 한다.

**⑤ 잊기 전에 다시 만난다 (간격 반복).**
교정은 그 자리에서 끝나지 않는다. 승격된 항목은 **1 → 3 → 7 → 16 → 35 세션** 간격으로
다시 나타나고, 맞히면 간격이 벌어지고 틀리면 처음으로 되감긴다. 다섯 상자를 통과하면
졸업한다. **이것이 "서서히 진화하는 학습"의 실체다** — 기분이 아니라 스케줄이다.

**⑥ 시험을 보지 않고 시험한다 (동적 평가).**
레벨 테스트를 따로 치지 않는다. 튜터는 대화 중 약 6턴마다 **한 단계 위 표현을 슬쩍
심고**(probe), 학습자가 그것을 처리했는지 관찰한다. 두 번 연속 통과하면 **그 자리에서**
말하는 수준을 올리고, 두 번 연속 놓치면 문장을 짧게 줄인다. 세션이 끝나면 대화 전체를
분석해 **어느 축이 약한지**와 **다음에 무엇을 보충할지**를 처방한다.

**⑦ 교정이 대화를 멈추게 하지 않는다.**
튜터가 교정을 *도구 호출*로 처리하면, 모델은 그 호출을 다 써 내려갈 때까지 **입을 다문다**.
한 턴에 생성 왕복이 두 번 일어나고, 교정이 꼼꼼할수록 대화가 끊긴다 — 설계가 스스로를
방해한다. 그래서 v0.2.0부터 교정은 **대화 경로 밖**에서 일어난다: 튜터는 그냥 말하고,
별도의 조용한 분석가가 발화를 읽어 화면에 카드를 올린다. 말은 멈추지 않는다.

## 방법론 — 철학이 실제로 하는 일

### 세션의 3막
1. **워밍업** — 복습 큐에서 최대 3개. 지난 오류를 먼저 만난다.
2. **본 대화** — 선택한 모드로. 교정은 정책대로, 난이도는 probe로 조정된다.
3. **마무리** — 오늘의 카드 + **분석 리포트**(오류 축 분포 · 소화율 · 다음 처방).

### 모드 (무엇을 연습할 것인가)
| 모드 | 언제 |
|---|---|
| **자유 회화** | 발화량이 목적일 때 — 관심사로 그냥 떠든다 |
| **상황별** | 실제 상황 예행연습 — 공항·식당·호텔·쇼핑·병원·면접·회의·전화·스몰토크·길찾기 |
| **집중 훈련** | 내가 반복해 틀리는 것만 여러 상황에서 |
| **복습** | 복습 큐만 — 잊기 직전 항목들 |
| **섀도잉** | 듣고 그대로 따라 말하기 — 발음·리듬 |

### 교정 방식 (피드백을 어떻게 받을 것인가) — 설정의 핵심
| 정책 | 대화 중 행동 | 화면 | 누구에게 |
|---|---|---|---|
| **흐름 우선** | 말로는 **절대** 끊지 않는다 | 카드로만 표시 | 입이 안 떨어지는 단계 |
| **되풀이**(기본) | 올바른 형태로 자연스럽게 되받는다 | 카드 + 되풀이 | 대부분의 학습자 |
| **즉시 교정** | 중요한 오류에서 끊고 다시 말하게 한다 | 카드 + 즉시 | 시험 준비·상급자 |

> 화면 카드는 **모든 정책에서 항상** 쌓인다. 말로 언제 개입하느냐만 달라진다.
> 대화는 사라지지만 화면은 남기 때문이다.

### 약점 → 처방 (분석의 결론은 숫자가 아니라 다음 행동이다)
| 가장 많은 오류 축 | 다음 세션 |
|---|---|
| 문법 | **집중 훈련**으로 같은 구조를 여러 상황에서 반복 |
| 어휘 | **상황극**으로 옮겨 필요한 말을 실제로 써 보게 |
| 발음 | **섀도잉** 비중을 올린다 |
| 말투·격식 | **면접·회의** 상황 + 즉시 교정 |
| 유창성 | **자유 회화** + 교정을 **흐름 우선으로 낮춘다** |

마지막 줄이 이 에이전트의 성격을 보여준다. 말이 끊길 때 대부분의 앱은 교정을 늘리지만,
여기서는 **줄인다**. 철학 ①이 설정을 이긴다.

### 개인별 학습 설정
**언어 / 레벨 / 모드 / 교정 방식**에 더해 **학습 목적 / 관심사 / 체험 방식 / 설명 언어**를
에이전트 목록 → Settings에서 바꾼다. 학습 언어 순서는 Cosmos에게 말로 지정할 수 있다.
교정 개수 상한·복습 간격·승격 조건·측정 주기는 학습 규칙이 정한다.

## 전용 화면 (🧩 에이전트 뷰)

말은 사라진다. 학습자가 붙잡을 수 있는 것은 화면에 남는 카드다.

- **오늘** — 교정은 **틀린 말(취소선) ↔ 고친 말(강조)** 을 나란히 놓은 전용 카드로
  보여준다. 문단으로 늘어놓으면 무엇이 어떻게 바뀌었는지 읽히지 않기 때문이다
  (v0.1.0의 실패에서 배운 것). 각 카드에 한 줄 이유와 사용 예문, **🔊 발음 듣기**가
  붙는다(웹은 브라우저 음성, 데스크톱은 OS 음성). 새 단어는 별도 카드로.
- **복습** — 지금 볼 것 / 대기 중 / 몇 세션 뒤에 돌아오는지. 바로 복습 세션 시작.
- **분석** — 한 단계 위 표현 소화율, 지난 교정 재현율, **오류 축 분포 막대**,
  보충 처방(그 모드로 바로 시작하는 버튼), 레벨 재분석 제안, 세션 이력.
- **설정** — 언어 11종 · 레벨 5단계 · 모드 5종 · 교정 3종, 개인별 학습 설정 폼.

화면은 코스모스의 **선언적 뷰 계약**(`cosmos/contracts/view.py`)으로 그린다. 이 에이전트는
HTML을 주지 않고 데이터를 준다 — 그래서 웹 셸과 데스크톱 셸에서 **같은 화면**이 나온다.

## 튜터가 부르는 도구

| action | 언제 | 하는 일 |
|---|---|---|
| `start` | 대화 시작 | 프로필·복습 큐·이번 세션의 규칙을 모델에 주입 |
| `finish` | 세션 종료 | 전체 분석 + 처방 + 레벨 재분석, 다음 세션 기본값 반영 |
| `set` / `status` | 학습자가 요청할 때 | 언어·레벨·모드·교정 방식 |

**대화 중에는 아무 도구도 부르지 않는다.** 교정·단어·수준 측정은 전부 백그라운드
관찰(`observe_turn`)에서 일어나고 화면으로만 간다 — 그것이 말을 끊지 않는 유일한 방법이다.
아래는 남아 있는 보조 경로(수동 기록·복습 채점)이며 대화 중에는 쓰지 않는다.

| 보조 action | 용도 |
|---|---|
| `note_error` / `note_word` / `note_probe` | 수동 기록(테스트·도구 연동) |
| `review_answer` | 복습 항목 채점 |
| `report` | 분석 요청 | 약점 축·소화율·처방 |

## 코스모스와 어떻게 협업하는가 (v0.5.0)

이 에이전트는 **혼자 가르치지 않는다.** 당신이 언어를 배우고 싶어서 설치한 것이므로,
*무엇을 배우는 중이고 · 어디까지 왔고 · 무엇을 어려워하는지* 를 코스모스가 함께 알아야
대화가 이어진다. 그래서 두 가지가 오간다.

### ① 기억 — 적은 것만, 오래 가는 것만

| 어디에 | 무엇이 | 왜 |
|---|---|---|
| **코스모스 기억** | 배우는 언어 · 대략의 수준 · 자꾸 걸리는 축 | 나중에도 참이고, 대화 중에 쓰인다 |
| **이 에이전트 폴더** | 카드 하나하나 · 복습 일정 · 세션 기록 | 수백 개가 매 세션 바뀐다 |

카드를 전부 기억에 넣으면 당신이 다른 것을 찾을 때 **그 카드들이 검색을 덮는다.**
그래서 올라가는 것은 *"스페인어를 배우는 중이고, 문법에서 자주 막힌다"* 정도다.
세션이 끝날 때 한 번 적고, 다음 세션을 시작할 때 되읽는다 — 그래서 매번 처음부터
묻지 않는다.

지운 기억은 되살아나지 않고, 이 에이전트가 남긴 것은 출처가 `lingua.v1`로 표시되어
**한꺼번에 걷어낼 수 있다.** 에이전트를 떼면 기록도 함께 정리된다는 뜻이다.

### ② 이어가자는 제안 — ★그리고 그만하라고 할 수 있다★

조용한 시간에, 복습이 밀렸거나 며칠 쉬었으면 코스모스가 **먼저** 물어본다.
*"스페인어 복습 열두 개 밀렸는데 지금 볼까요?"* — 그렇다고 하면 바로 시작된다.

들이대지 않도록 문이 여럿 걸려 있다:

- 잡담 중이면 안 꺼낸다
- 방금 연습했으면 안 꺼낸다
- 말하는 중간에는 안 끼어든다
- ★**물리면 뜸해진다**★ — 한 번 거절하면 하루, 두 번이면 닷새, 계속 거절하면 **먼저 꺼내지 않는다**

### ③ 세 가지 자세 — 말로도, 버튼으로도

| 자세 | 뜻 | 어떻게 |
|---|---|---|
| **집중** | 지금 연습하는 중. 적극적으로 교정한다 | *"스페인어 연습하자"* → 저절로 집중이 된다 |
| **배경**(기본) | 조용히 있다가 필요할 때만 얹는다 | 수업이 끝나면 **저절로** 돌아온다 |
| **조용** | 지금은 아무것도 하지 마 | *"교정하지 마"* · 카드의 단추 |

★에이전트 이름을 외울 필요는 없다★ — *"교정하지 마"* 처럼 **하는 일로** 말하면
코스모스가 알아서 이것을 고른다. 그냥 *"조용히 해"* 는 코스모스 전체를 향한 말이라
이 에이전트만 끄지는 않는다.

⚠️ **조용은 저절로 풀리지 않는다.** 당신이 껐으니 당신이 켤 때까지 그대로다
(집중만 시간이 지나면 배경으로 돌아온다). 지금 조용한 상태인지는 카드에 표시된다.

## 개인정보

학습 기록의 **본체**(설정·카드·복습 상자·측정값)는 Cosmos 저장 제공자의 사용자별
에이전트 상태에 저장된다(로컬 SQLite / 호스팅은 구성된 저장 제공자).
구형 `agentdata/lingua-live/state.json`은 단일 사용자 로컬(`local`)에서만 자동 이전하고
원본은 남긴다. 소유자를 알 수 없는 공유 파일을 다른 계정에 자동 배정하지 않는다.
기명 사용자에게 구형 기록을 옮기려면 소유자 확인을 동반한 별도 이전이 필요하다.
대화·분석은 Cosmos가 선택한 모델을 사용하므로 그 모델의 데이터 처리 정책이 적용된다.

요구하는 표준 역량은 **`memory` 하나**다(v0.5.0에서 생겼다). 위 표에 적은 세 가지 —
배우는 언어 · 대략의 수준 · 자꾸 걸리는 축 — 를 코스모스 기억에 적기 위한 것이고,
그 밖의 것은 올리지 않는다. 대화 내용 자체는 코스모스의 기억 정책을 따른다.
