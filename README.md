# Lingua Live — 실시간 언어 학습 에이전트

> 코스모스(cosmos-billy) 마켓 에이전트. 음성으로 대화하면서 **수준을 재고, 흐름을 끊지
> 않고 교정하고, 잊을 때쯤 다시 꺼내 주는** 튜터.
> 영어 · 스페인어 · 일본어 · 중국어 · 독일어 · 프랑스어 · 한국어 · 아랍어
> (+ 이탈리아어 · 포르투갈어 · 러시아어)

설치: 코스모스 **🛒 마켓 → Lingua Live → 설치**. 화면은 **🧩 에이전트 뷰**에 열린다.

---

## 왜 또 하나의 언어 앱이 아닌가

대부분의 언어 학습 도구는 **정확도**를 최적화한다. 틀리면 즉시 알려주고, 점수를 매기고,
다음 문제로 넘어간다. 그런데 사람이 외국어를 못 하게 되는 진짜 이유는 문법을 몰라서가
아니라 **입이 안 떨어져서**다. 즉시 교정은 정확도를 잠깐 올리는 대신 발화량을 줄이고
불안을 키운다. 말을 덜 하게 만드는 학습법은, 아무리 정확해도 실패한다.

Lingua Live는 그 반대 순서를 택한다: **먼저 말하게 하고, 교정은 흐름을 지키며 주고,
그 교정이 사라지지 않게 시간을 두고 되돌린다.**

## 교육 철학 (이 일곱 줄이 모든 설정의 근거다)

**① 말이 멈추면 학습도 멈춘다.**
발화량이 곧 연습량이다. 그래서 기본 교정 방식은 대화를 끊지 않는 **되풀이(recast)** 다 —
학습자가 한 말을 올바른 형태로 자연스럽게 되받아 주고 계속 간다. 즉시 교정은 *선택*이지
기본이 아니다.

**② 한 걸음 위를 듣는다 (i+1).**
지금 수준에서만 놀면 늘지 않고, 너무 어려우면 닫힌다. 튜터는 늘 **한 단계 위**로 말한다.
그 '한 단계'는 고정값이 아니라 실측으로 움직인다(→ ⑥).

**③ 이해했다고 아는 게 아니다 (밀어붙인 산출).**
알아듣는 것과 말할 수 있는 것은 다르다. 교정 뒤에는 **다시 말해보기**를 요구한다.

**④ 모든 오류를 고치지 않는다.**
한 번에 다 고치면 하나도 남지 않는다. 같은 오류가 **두 번** 반복될 때만 승격하고,
한 세션에서 다루는 교정 항목은 **최대 3개**다. 나머지는 조용히 기록만 한다.

**⑤ 잊기 전에 다시 만난다 (간격 반복).**
교정은 그 자리에서 끝나지 않는다. 승격된 항목은 **1 → 3 → 7 → 16 → 35 세션** 간격으로
다시 나타나고, 맞히면 간격이 벌어지고 틀리면 처음으로 되감긴다. 다섯 상자를 통과하면
졸업한다. **이것이 "서서히 진화하는 학습"의 실체다** — 기분이 아니라 스케줄이다.

**⑥ 시험을 보지 않고 시험한다 (동적 평가).**
레벨 테스트를 따로 치지 않는다. 튜터는 대화 중 약 6턴마다 **한 단계 위 표현을 슬쩍
심고**(probe), 학습자가 그것을 처리했는지 관찰한다. 두 번 연속 통과하면 **그 자리에서**
말하는 수준을 올리고, 두 번 연속 놓치면 문장을 짧게 줄인다. 세션이 끝나면 대화 전체를
분석해 **어느 축이 약한지**와 **다음에 무엇을 보충할지**를 처방한다.

**⑦ 교정이 대화를 멈추게 하지 않는다.**
튜터가 교정을 *도구 호출*로 처리하면, 모델은 그 호출을 다 써 내려갈 때까지 **입을 다문다**.
한 턴에 생성 왕복이 두 번 일어나고, 교정이 꼼꼼할수록 대화가 끊긴다 — 설계가 스스로를
방해한다. 그래서 v0.2.0부터 교정은 **대화 경로 밖**에서 일어난다: 튜터는 그냥 말하고,
별도의 조용한 분석가가 발화를 읽어 화면에 카드를 올린다. 말은 멈추지 않는다.

## 방법론 — 철학이 실제로 하는 일

### 세션의 3막
1. **워밍업** — 복습 큐에서 최대 3개. 지난 오류를 먼저 만난다.
2. **본 대화** — 선택한 모드로. 교정은 정책대로, 난이도는 probe로 조정된다.
3. **마무리** — 오늘의 카드 + **분석 리포트**(오류 축 분포 · 소화율 · 다음 처방).

### 모드 (무엇을 연습할 것인가)
| 모드 | 언제 |
|---|---|
| **자유 회화** | 발화량이 목적일 때 — 관심사로 그냥 떠든다 |
| **상황별** | 실제 상황 예행연습 — 공항·식당·호텔·쇼핑·병원·면접·회의·전화·스몰토크·길찾기 |
| **집중 훈련** | 내가 반복해 틀리는 것만 여러 상황에서 |
| **복습** | 복습 큐만 — 잊기 직전 항목들 |
| **섀도잉** | 듣고 그대로 따라 말하기 — 발음·리듬 |

### 교정 방식 (피드백을 어떻게 받을 것인가) — 설정의 핵심
| 정책 | 대화 중 행동 | 화면 | 누구에게 |
|---|---|---|---|
| **흐름 우선** | 말로는 **절대** 끊지 않는다 | 카드로만 표시 | 입이 안 떨어지는 단계 |
| **되풀이**(기본) | 올바른 형태로 자연스럽게 되받는다 | 카드 + 되풀이 | 대부분의 학습자 |
| **즉시 교정** | 중요한 오류에서 끊고 다시 말하게 한다 | 카드 + 즉시 | 시험 준비·상급자 |

> 화면 카드는 **모든 정책에서 항상** 쌓인다. 말로 언제 개입하느냐만 달라진다.
> 대화는 사라지지만 화면은 남기 때문이다.

### 약점 → 처방 (분석의 결론은 숫자가 아니라 다음 행동이다)
| 가장 많은 오류 축 | 다음 세션 |
|---|---|
| 문법 | **집중 훈련**으로 같은 구조를 여러 상황에서 반복 |
| 어휘 | **상황극**으로 옮겨 필요한 말을 실제로 써 보게 |
| 발음 | **섀도잉** 비중을 올린다 |
| 말투·격식 | **면접·회의** 상황 + 즉시 교정 |
| 유창성 | **자유 회화** + 교정을 **흐름 우선으로 낮춘다** |

마지막 줄이 이 에이전트의 성격을 보여준다. 말이 끊길 때 대부분의 앱은 교정을 늘리지만,
여기서는 **줄인다**. 철학 ①이 설정을 이긴다.

### 설정은 넷뿐이다
**언어 / 레벨 / 모드 / 교정 방식.** 나머지(교정 개수 상한, 복습 간격, 승격 조건, 난이도
측정 주기)는 사용자가 만지는 손잡이가 아니라 **철학이 정한 상수**다. 손잡이가 많은 것은
유연한 게 아니라 결정을 사용자에게 떠넘기는 것이다.

## 전용 화면 (🧩 에이전트 뷰)

말은 사라진다. 학습자가 붙잡을 수 있는 것은 화면에 남는 카드다.

- **오늘** — 교정은 **틀린 말(취소선) ↔ 고친 말(강조)** 을 나란히 놓은 전용 카드로
  보여준다. 문단으로 늘어놓으면 무엇이 어떻게 바뀌었는지 읽히지 않기 때문이다
  (v0.1.0의 실패에서 배운 것). 각 카드에 한 줄 이유와 사용 예문, **🔊 발음 듣기**가
  붙는다(웹은 브라우저 음성, 데스크톱은 OS 음성). 새 단어는 별도 카드로.
- **복습** — 지금 볼 것 / 대기 중 / 몇 세션 뒤에 돌아오는지. 바로 복습 세션 시작.
- **분석** — 한 단계 위 표현 소화율, 지난 교정 재현율, **오류 축 분포 막대**,
  보충 처방(그 모드로 바로 시작하는 버튼), 레벨 재분석 제안, 세션 이력.
- **설정** — 언어 8종 · 레벨 5단계 · 모드 5종 · 교정 3종.

화면은 코스모스의 **선언적 뷰 계약**(`cosmos/contracts/view.py`)으로 그린다. 이 에이전트는
HTML을 주지 않고 데이터를 준다 — 그래서 웹 셸과 데스크톱 셸에서 **같은 화면**이 나온다.

## 튜터가 부르는 도구

| action | 언제 | 하는 일 |
|---|---|---|
| `start` | 대화 시작 | 프로필·복습 큐·이번 세션의 규칙을 모델에 주입 |
| `finish` | 세션 종료 | 전체 분석 + 처방 + 레벨 재분석, 다음 세션 기본값 반영 |
| `set` / `status` | 학습자가 요청할 때 | 언어·레벨·모드·교정 방식 |

**대화 중에는 아무 도구도 부르지 않는다.** 교정·단어·수준 측정은 전부 백그라운드
관찰(`observe_turn`)에서 일어나고 화면으로만 간다 — 그것이 말을 끊지 않는 유일한 방법이다.
아래는 남아 있는 보조 경로(수동 기록·복습 채점)이며 대화 중에는 쓰지 않는다.

| 보조 action | 용도 |
|---|---|
| `note_error` / `note_word` / `note_probe` | 수동 기록(테스트·도구 연동) |
| `review_answer` | 복습 항목 채점 |
| `report` | 분석 요청 | 약점 축·소화율·처방 |

## 개인정보

학습 기록(설정·카드·복습 상자·측정값)은 **당신 기기의 코스모스 데이터 폴더**
(`agentdata/lingua-live/state.json`)에만 저장된다. 이 에이전트는 네트워크를 쓰지 않고,
표준 역량(`capabilities`)을 하나도 요구하지 않는다. 대화 내용 자체는 코스모스의 기억
정책을 따른다.
